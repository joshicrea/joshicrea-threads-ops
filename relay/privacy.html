Privacy Policy - Threads Ops Assistant

Last updated: 2026-09-20

Threads Ops Assistant (the "App", registered on Meta as "スレッズ自動化") is a desktop tool that helps a Threads account owner research reference posts, draft posts, review replies, and read insights for their own account. The App is operated by Daichi Hayashi (contact: info@bizcrea.com).

1. What the App accesses

With the user's authorization through Threads Login, the App accesses the following data through the Threads API: the user's Threads profile (user ID and username), posts published by the user, replies to those posts, insights (views, likes, replies, reposts, quotes) for those posts, and public posts returned by keyword search.

2. Where the data is stored

All data, including the access token, is stored only on the user's own computer, in a local file inside the App folder. The App runs on the user's computer and does not send any data to a server operated by us. We, the operator, never receive or store the user's data.

3. How the data is used

The data is used only to show the user their own posts and replies, to draft new posts and replies for the user's approval, and to generate analysis of the user's own results. Nothing is published to Threads without an explicit action by the user in the App. Post drafts and analysis may be generated by an AI service chosen and configured by the user (for example Anthropic Claude or Google Gemini); in that case the text of reference posts and the user's own posts is sent to that service under its terms.

4. Sharing

We do not sell, share, or transfer any user data to third parties. Data leaves the user's computer only when the user chooses to publish a post or reply to Threads, or when the App calls the AI service the user configured.

5. Deletion

The user can delete all data at any time by pressing "Disconnect" in the App settings (which removes the token) or by deleting the App folder on their computer. Removing the App from Threads (Settings > Account > Website permissions) revokes the App's access. Data deletion requests can also be sent to info@bizcrea.com.

6. Contact

Daichi Hayashi, info@bizcrea.com

プライバシーポリシー - Threads運用アシスタント

最終更新日: 2026年9月20日

Threads運用アシスタント（Meta 上の登録名「スレッズ自動化」。以下「本アプリ」）は、Threads アカウントの所有者が自分のアカウントについて、参考投稿の調査・投稿の下書き・返信の確認・インサイトの閲覧を行うためのデスクトップツールです。運営者は林大地（連絡先: info@bizcrea.com）です。

1. 本アプリが取得する情報

利用者が Threads ログインで許可した範囲で、Threads API を通じて次の情報を取得します。利用者のプロフィール（ユーザーIDとユーザー名）、利用者が公開した投稿、その投稿への返信、その投稿のインサイト（閲覧数・いいね・返信・再投稿・引用）、キーワード検索で返される公開投稿。

2. 情報の保存場所

アクセストークンを含むすべての情報は、利用者自身のパソコンの中（本アプリのフォルダ内のファイル）にだけ保存されます。本アプリは利用者のパソコン上で動作し、運営者のサーバーに情報を送ることはありません。運営者は利用者の情報を受け取らず、保持しません。

3. 情報の利用目的

取得した情報は、利用者自身の投稿と返信の表示、利用者が承認するための投稿・返信の下書き作成、利用者自身の実績の分析にだけ使います。利用者が本アプリ上で明示的に操作しない限り、Threads に投稿されることはありません。下書きや分析は、利用者が選んで設定した AI サービス（例: Anthropic Claude、Google Gemini）で生成することがあり、その場合は参考投稿と利用者自身の投稿の本文が、そのサービスの規約のもとで送信されます。

4. 第三者提供

利用者の情報を第三者に販売・共有・譲渡することはありません。情報が利用者のパソコンの外に出るのは、利用者が投稿や返信を Threads に公開する操作をしたとき、または利用者が設定した AI サービスを本アプリが呼び出すときだけです。

5. 削除

利用者は、本アプリの設定画面で「連携を解除」を押す（トークンを削除します）か、パソコン上の本アプリのフォルダを削除することで、いつでもすべての情報を削除できます。Threads 側（設定 → アカウント → ウェブサイトのアクセス許可）から本アプリを削除すると、本アプリのアクセス権が取り消されます。削除の依頼は info@bizcrea.com でも受け付けます。

6. 連絡先

林大地　info@bizcrea.com
