Privacy Policy - Threads Ops Assistant

Last updated: 2026-10-20

Threads Ops Assistant (the "App", registered on Meta as "スレッズ自動化") is a desktop tool that helps a Threads account owner research reference posts, draft posts, review replies, and read insights for their own account. The App is operated by Daichi Hayashi (contact: info@bizcrea.com).

1. What the App accesses

With the user's authorization through Threads Login, the App accesses the following data through the Threads API: the user's Threads profile (user ID and username), posts published by the user, replies to those posts, insights (views, likes, replies, reposts, quotes) for those posts, and, only if the user has granted that permission, public posts returned by keyword search.

2. Where the data is stored

All data, including the access token, is stored only on the user's own computer, in a local file inside the App folder. The App runs on the user's computer.

Connection relay: when the user connects the App to Threads, the authorization code returned by Threads Login is sent to a connection relay operated by us (https://bizcrea.com/oauth-host). The relay exchanges the code for an access token using the App's secret, and returns the token to the user's computer. The relay does not store the access token. The authorization code, which can be used only once and expires within minutes, may remain in the standard access log of our web server, because Threads returns it in the address of our callback page. The web server's access log also records the IP address and browser information of each request, as web servers normally do. For operation and troubleshooting, the relay records the time, the user's Threads username and user ID, and our internal customer identifier; we keep these records while we provide the service to the user, and delete them when the service ends or on request. The relay also keeps, for each customer, the expected Threads username and a hash of the customer's connection passphrase, in order to allow only that customer's account to connect. Before the App extends the access token (about once every 50 days), it sends the customer's connection passphrase and Threads username to the relay to confirm that the service is still active; the relay checks them in the same way and records the time, the username, and our internal customer identifier.

3. How the data is used

The data is used only to show the user their own posts and replies, to draft new posts and replies for the user's approval, and to generate analysis of the user's own results. Nothing is published to Threads without an explicit action by the user in the App. Post drafts and analysis may be generated by an AI service chosen and configured by the user (for example Anthropic Claude or Google Gemini); in that case the text of reference posts and the user's own posts is sent to that service under its terms.

4. Sharing

We do not sell, share, or transfer any user data to third parties. Data leaves the user's computer only when the user connects to Threads through the connection relay described in section 2, when the App confirms with that relay before extending the access token, when the user chooses to publish a post or reply to Threads, or when the App calls the AI service the user configured.

5. Deletion

The user can delete all data stored on their computer at any time by pressing "Disconnect" in the App settings (which removes the token) or by deleting the App folder on their computer. The records kept by the connection relay (section 2) are deleted by us when the service ends or when the user asks. Removing the App from Threads (Settings > Account > Website permissions) revokes the App's access. Data deletion requests can also be sent to info@bizcrea.com.

6. Contact

Daichi Hayashi, info@bizcrea.com

プライバシーポリシー - Threads運用アシスタント

最終更新日: 2026年10月20日

Threads運用アシスタント（Meta 上の登録名「スレッズ自動化」。以下「本アプリ」）は、Threads アカウントの所有者が自分のアカウントについて、参考投稿の調査・投稿の下書き・返信の確認・インサイトの閲覧を行うためのデスクトップツールです。運営者は林大地（連絡先: info@bizcrea.com）です。

1. 本アプリが取得する情報

利用者が Threads ログインで許可した範囲で、Threads API を通じて次の情報を取得します。利用者のプロフィール（ユーザーIDとユーザー名）、利用者が公開した投稿、その投稿への返信、その投稿のインサイト（閲覧数・いいね・返信・再投稿・引用）、利用者がその権限を許可した場合に限り、キーワード検索で返される公開投稿。

2. 情報の保存場所

アクセストークンを含むすべての情報は、利用者自身のパソコンの中（本アプリのフォルダ内のファイル）にだけ保存されます。本アプリは利用者のパソコン上で動作します。

連携の中継: 利用者が本アプリを Threads と連携するとき、Threads ログインが返す認可コードは、運営者が運用する連携の中継（https://bizcrea.com/oauth-host）に送られます。中継は本アプリのシークレットを使って認可コードをアクセストークンに交換し、そのトークンを利用者のパソコンに返します。中継はアクセストークンを保存しません。認可コードは、Threads が運営者のコールバックページのアドレスに付けて返すため、Webサーバー標準のアクセスログに残ることがあります（認可コードは1回しか使えず、数分で無効になります）。また、Webサーバーのアクセスログには、一般的なWebサーバーと同じく、アクセス元の IP アドレスとブラウザの情報が記録されます。運用と不具合の調査のため、中継は日時、利用者の Threads ユーザー名とユーザーID、運営者の内部の顧客識別子を記録します。この記録は、利用者にサービスを提供している間保存し、提供の終了時または依頼があったときに削除します。また中継は、そのお客様のアカウントだけが連携できるよう、お客様ごとに、連携先として期待する Threads ユーザー名と、お客様の連携用の合言葉のハッシュ値を保持します。本アプリは、アクセストークンの期限を延長する前（約50日に1回）に、サービスが続いているかを確かめるため、お客様の連携用の合言葉と Threads ユーザー名を中継に送ります。中継はこれを同じ方法で照合し、日時、ユーザー名、運営者の内部の顧客識別子を記録します。

3. 情報の利用目的

取得した情報は、利用者自身の投稿と返信の表示、利用者が承認するための投稿・返信の下書き作成、利用者自身の実績の分析にだけ使います。利用者が本アプリ上で明示的に操作しない限り、Threads に投稿されることはありません。下書きや分析は、利用者が選んで設定した AI サービス（例: Anthropic Claude、Google Gemini）で生成することがあり、その場合は参考投稿と利用者自身の投稿の本文が、そのサービスの規約のもとで送信されます。

4. 第三者提供

利用者の情報を第三者に販売・共有・譲渡することはありません。情報が利用者のパソコンの外に出るのは、第2条の連携の中継を通して Threads と連携するとき、アクセストークンの期限を延長する前にその中継へ確かめるとき、利用者が投稿や返信を Threads に公開する操作をしたとき、または利用者が設定した AI サービスを本アプリが呼び出すときだけです。

5. 削除

利用者は、本アプリの設定画面で「連携を解除」を押す（トークンを削除します）か、パソコン上の本アプリのフォルダを削除することで、いつでも利用者のパソコンにある情報をすべて削除できます。第2条の連携の中継が保持する記録は、提供の終了時または依頼があったときに運営者が削除します。Threads 側（設定 → アカウント → ウェブサイトの権限）から本アプリを削除すると、本アプリのアクセス権が取り消されます。削除の依頼は info@bizcrea.com でも受け付けます。
