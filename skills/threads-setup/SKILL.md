# 初回セットアップ

目的: 利用者が投稿案を作れる状態にする。聞くのは投稿の質を決める4つだけ。それ以外は聞かない。

## 手順

### 0. 本体の確認

`threads_status` を呼ぶ。接続できなければ「`~/.claude/threads-ops/app/起動.cmd`（Mac は `起動.command`）をダブルクリックしてください（PC を再起動すれば自動で動きます）」と案内し、動いたら続ける。

### 1. 発信者情報（1問ずつ・利用者の言葉をそのまま使う）

| 順 | 聞くこと | 保存先 |
|---|---|---|
| 1 | 発信者の名前（アカウントで名乗っている名前） | brandName |
| 2 | どんな人に、何を届けたいか（2〜3行でよい。仕事・得意・実績・想い） | profile |
| 3 | 文体の好み（例: です・ます／短文／絵文字なし／一人称は私）と、書きたくないこと | writingRules |
| 4 | 投稿の最後に入れたい一言や誘導先があれば（無ければ空でよい） | defaultCta |

4つ揃ったら `threads_update_settings` で保存し、保存した内容を短く読み上げて確認する。

### 2. AI の接続

`threads_ai_check` を呼ぶ。成功したら「AI は使えます」と伝える。失敗したら:

- 「Claude Code がこのPCに見つかりません」→ Claude Code のインストールとログインを案内
- 「ログインしていません」→ ターミナルで `claude` を起動して /login
- Claude Code 以外を使いたいと言われたら、画面（http://localhost:4173 の設定タブ）で切り替えるよう案内。キーの値はチャットで受け取らない

### 3. Threads 連携

`threads_status` の threads.connected が false なら、次の順で案内する。

1. 提供元から届いている「テスター招待」を、Threads アプリの 設定 → アカウント → Threads テスター招待 で承認してもらう（承認していないと連携が「The user has not accepted the invite」で止まる）
2. 提供元から届いている App ID と App Secret を、画面（http://localhost:4173）の設定タブ「2. Threads連携」に入れて「保存」してもらう。値はチャットに貼らないよう伝える。届いていなければ、提供元に「App ID と App Secret」を請求してもらう（これが無いと次の手順が「Threads App IDが未設定です」で止まる）
3. `threads_auth_url` で URL を取り、ブラウザで開いて許可してもらう。「Threads App IDが未設定です」と返ったら 2 に戻る。戻ってきたら `threads_status` で connected を確かめる

### 4. 運用の初期値

聞かずに既定のままにする（予約時刻 07/09/11/13/15/17/19/21 時、コメント自動取り込み ON、自動返信 OFF、予約投稿の自動送信 OFF）。「自動返信を ON にしますか」だけは聞き、ON にするなら「AI が判定して自動で返信し、クレーム等は要確認に残す」と一言添えてから `threads_update_settings` で autoReplyEnabled を true にする。

### 5. 締め

「次は『投稿案を作って』と言ってください。目的とテーマを聞いて8本作ります」で終える。
