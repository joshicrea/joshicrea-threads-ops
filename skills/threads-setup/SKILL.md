# 初回セットアップ

目的: 利用者が投稿案を作れる状態にする。聞くのは投稿の質を決める4つと、任意の発信テーマだけ。それ以外は聞かない。

利用者はパソコンや文章の専門家ではない前提で進める。1回に1問だけ聞き、答えにくそうなら例を1つ見せる。

## 手順

### 0. 本体の確認

`threads_status` を呼ぶ。接続できなければ「`~/.claude/threads-ops/app/起動.cmd`（Mac は `起動.command`）をダブルクリックしてください（PC を再起動すれば自動で動きます）」と案内し、動いたら続ける。

### 1. 発信者情報（1問ずつ・利用者の言葉をそのまま使う）

| 順 | 聞くこと | 保存先 |
|---|---|---|
| 1 | 発信者の名前（アカウントで名乗っている名前） | brandName |
| 2 | どんな人に、何を届けたいか（2〜3行でよい。仕事・得意・実績・想い） | profile |
| 3 | 文体（下の「文体の決め方」で下書きを作る） | writingRules |
| 4 | 投稿の最後に入れたい一言や誘導先があれば（無ければ空でよい） | defaultCta |
| 5（任意） | 返信だけ口調を変えたいか（無ければ空。空なら3の文体に合わせる） | replyStyle |
| 6（任意） | 投稿で見せられるもの（作品・商品・日常・実績・こだわり。写真が無くても、書けるものでよい。無ければ空） | materials |
| 7（任意） | 素材をまとめたフォルダがあれば、このパソコン上のパス（中の .md と .txt を読む。無ければ空） | materialFolder |

#### 文体の決め方（3番）

自分の文体を言葉で説明できる人は少ない。好みを聞く前に、次の順で進める。

1. 「これまでに自分で書いた文章を2〜3本、ここに貼ってもらえますか。Threads・Instagram・ブログ・LINE・メルマガ、どれでもかまいません」と頼む
2. 貼ってもらえたら、そこから次を読み取り、writingRules の下書きを3〜6行で作る: 語尾（です・ます／だ・である／話し言葉）、一文の長さ、改行の多さ、絵文字の有無と種類、一人称、よく使う言い回し、書き出しと締めの型
3. 下書きを見せて「この書き方で合っていますか。直したいところがあれば言ってください」と聞く。直しを反映してから保存する
4. 「書きたくないこと・使いたくない言葉はありますか」と1問だけ聞き、あれば下書きに足す
5. 貼れる文章が無いときだけ、好みを聞く（例を見せる: です・ます／短めの文／絵文字は使わない／一人称は私）

貼ってもらった文章そのものは保存しない。読み取った決まりごとだけを writingRules に書く。

#### 保存

1〜4が揃ったら `threads_update_settings` で保存し、保存した内容を短く読み上げて確認する。5〜7は、答えがあったものだけ保存する（無理に聞き出さない）。

### 1-2. 発信テーマ（任意）

「発信したい話題が2つ以上ありますか。たとえば本業の話と、趣味や同じ世代向けの話を混ぜたい、などです」と1問だけ聞く。

- 無ければ飛ばす（テーマを登録しなくても投稿は作れる）
- あれば、テーマごとに「テーマ名」「誰に向けて」「出す量（よく・ときどき・たまに）」「何日に1回は必ず出したいか（無ければ指定なし）」を聞き、`threads_update_settings` の themes で保存する
- 期間の決まった宣伝（電子書籍の無料配布、イベント募集など）は、この場では聞かない。必要になったら「宣伝投稿を作って」と言えばよいと伝える

### 2. AI の接続

`threads_ai_check` を呼ぶ。成功したら「AI は使えます」と伝える。失敗したら:

- 「Claude Code がこのPCに見つかりません」→ Claude Code のインストールとログインを案内
- 「ログインしていません」→ ターミナルで `claude` を起動して /login
- Claude Code 以外を使いたいと言われたら、画面（http://localhost:4173 の設定タブ）で切り替えるよう案内。キーの値はチャットで受け取らない

### 3. Threads 連携

`threads_status` の threads.connected が false なら、`threads_status` の `next`（次にやること）に従い、次の順で案内する。

1. 提供元から届いている「連携コード」（TOPS1. で始まる1行）を、画面（http://localhost:4173）の設定タブ「2. Threads連携」の連携コード欄に貼って「保存」してもらう。コードには合言葉が入っているので、チャットには貼らないよう伝える。届いていなければ、提供元に「連携コード」を請求してもらう
2. 提供元から届いている「テスター招待」を、Threads アプリの 設定 → アカウント → ウェブサイトの権限 → テスター招待 で承認してもらう（承認していないと連携が「The user has not accepted the invite」で止まる）
3. 連携を押す前に、そのブラウザでログインしている Threads アカウントが、連携したいアカウントか確かめてもらう（別のアカウントでログインしていると、本体が止める）
4. `threads_auth_url` で URL を取り、ブラウザで開いて許可してもらう。戻ってきたら `threads_status` で connected と、連携済みのユーザー名を確かめる

App ID・App Secret・OAuth Host などの「詳しい設定」は、提供元に言われたときだけ触る。

### 4. 運用の初期値

聞かずに既定のままにする（予約時刻 07/09/11/13/15/17/19/21 時、コメント自動取り込み ON、自動返信 OFF、予約投稿の自動送信 OFF）。「自動返信を ON にしますか」だけは聞き、ON にするなら「AI が判定して自動で返信し、クレーム等は要確認に残す」と一言添えてから `threads_update_settings` で autoReplyEnabled を true にする。

### 5. 締め

「次は『リサーチして』と言ってください。同じジャンルで伸びている投稿を調べて、型を投稿案に生かします（1テーマで5〜10分ほど）。そのあと『投稿案を作って』で8本作ります」で終える。
